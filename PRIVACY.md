# Privacy Policy

Effective date: May 22, 2026

Faker BR does not collect, store, sell, or share user data with the developer.

## Data Collection

Faker BR does not collect personal information, browsing history, form contents, analytics, telemetry, or usage tracking data.

The extension does not send any data to the developer.

## External API Requests

Faker BR only makes external HTTPS requests when the user explicitly triggers a feature:

- BrasilAPI is used to look up CNPJ data entered or selected by the user.
- ViaCEP is used to look up CEP/address data entered or selected by the user.
- Mail.tm is used to create and access a temporary email inbox requested by the user.

These requests are made directly from the user's browser to the external service. Faker BR does not operate an intermediary server.

## Local Storage

Faker BR may store the following locally in the user's browser using `chrome.storage.local`:

- Extension preferences, such as language and selected data locale.
- Temporary Mail.tm inbox credentials and token, so the temporary inbox remains available when reopening the popup.

This information remains local to the user's browser and is not sent to the developer.

## Remote Code

Faker BR does not execute remote code. All executable code is included in the extension package submitted to the Chrome Web Store.

External services are used only as data APIs when requested by the user.
