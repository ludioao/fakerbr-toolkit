# Faker BR

Faker BR é uma extensão Manifest V3 para Google Chrome que gera dados brasileiros de teste e ajuda a preencher formulários durante desenvolvimento, QA, suporte e homologação.

Criado por Lúdio Oliveira.

## Instalação

1. Abra `chrome://extensions` no seu navegador.
2. Ative o "Modo do desenvolvedor" (canto superior direito).
3. Clique em "Carregar extensão sem compactação".
4. Selecione a pasta do projeto.

Após instalado, a extensão ficará disponível na barra de ferramentas do Chrome.
